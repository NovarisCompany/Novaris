# Novaris: Sistema de Gestión de TI
**Novaris** es una plataforma web de uso interno (intranet) destinada a centralizar la gestión de recursos tecnológicos y las actividades de soporte informático [[1, 2]].

## Módulos Principales
- [[Gestión de Inventario]]: Control integral de activos tecnológicos.
- [[Mesa de Ayuda]]: Seguimiento del ciclo de vida de incidencias mediante tickets.
- [[Gestión de Solicitudes]]: Trámites de instalación y configuración de red.
- [[Panel de Métricas]]: Dashboard para la toma de decisiones.
